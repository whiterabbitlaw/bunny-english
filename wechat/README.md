# 兔兔作业

给幼儿园老师布置一次英语作业的小程序。老师放图片和示范音频，家长带小朋友看图、逐段听音频，再交两段录音：句子一段、字母一段。

这不是网页里的听一听、配一配。网页继续用 GitHub Pages，不受这里影响。没有自动打分，没有游戏，没有班级统计。

仓库里没有 AppID，也没有云环境 ID。下面的云存储和数据库规则需要你在云开发控制台粘贴后才生效。本机测试没有调用云存储。

## 老师

1. 打开小程序，复制自己的 OPENID。
2. 把 OPENID 填进云函数环境变量 `TEACHER_OPENIDS`（逗号分隔，只放在云函数配置里）。小程序里没有“成为老师”的按钮。
3. 给小朋友起一个显示用的称呼，生成邀请，立刻发给家长。邀请不是名字或学号。离开页面后不能再查看，未绑定前可以重新生成。已经绑定的可以解除绑定，旧邀请同时失效；已经交过的录音还在。
4. 新建作业。每一块是一张相册图片，加上一段或多段示范音频。
5. 音频可以自己录，也可以从微信聊天里选文件。`wx.chooseMessageFile` 只能选会话里的文件，不能打开手机文件夹。
6. 先点“预览”，再点“发布给小朋友”。发布后这一份不能再改。
7. 在提交情况里看谁交了，并播放录音。

## 家长和小朋友

用老师发来的邀请打开。邀请一旦绑定，别人再用同一条链接会失败。

看每一块的图片，每段示范音频单独播放。录“句子”和“字母”两段，可以停止、试听、重录。勾选监护人同意后才会提交。提交一次之后不能再交。

## 导入开发者工具

1. 用微信开发者工具导入本仓库的 `wechat/` 目录（包含 `project.config.json` 的那一层）。
2. 在 `wechat/project.config.json` 和 `wechat/miniprogram/config.js` 填写同一个小程序 AppID。AppID 是标识，不是密钥。
3. 在 `wechat/miniprogram/config.js` 填写云环境 ID。
4. 不要把 AppSecret、云密钥或 `TEACHER_OPENIDS` 写进小程序代码。
5. 云函数目录是 `wechat/cloudfunctions/homework`。在工具里安装依赖并上传部署这个函数。上传前确认 `config.json` 里没有老师名单。
6. 没有 AppID 或云环境 ID 时，小程序只显示“需要配置”，并可以打开本地示例。示例写着不能上传、不能提交。

## 必须在控制台粘贴的规则

云函数是管理端，不受下面的客户端规则限制，所以权限判断写在函数里。规则文件是 `wechat/security-rules.json`。

四个集合 `children`、`assignments`、`submissions`、`files` 都设为：

```json
{ "read": false, "write": false }
```

云存储设为客户端不可读，只有文件所有者可写：

```json
{ "read": false, "write": "auth.openid == resource.openid" }
```

这是微信登录的写法（文档里的 `auth.openid`）。如果控制台只接受 `auth.uid`，改成 `"write": "auth.uid == resource.openid"`，`read` 仍然是 `false`。不要设成所有人可读。

云函数调用保持登录用户才能调用，不要设成 `"invoke": true`，也不要打开未登录访问。

老师名单是云函数环境变量 `TEACHER_OPENIDS`。改完后重新部署或等待函数读到新变量。

播放和老师听作业走云函数里的 `getTempFileURL`，请求 `maxAge` 300 秒。官方说明私有文件的临时链接默认大约 10 分钟。临时链接是否按 300 秒过期，要在你的环境里用真机确认。

## 真机检查

配置齐了以后，用两部手机或两个微信号核对：

- 未填写环境变量时，不能创建小朋友。
- 相册选图、聊天选音频、录示范音频，预览后发布。草稿在发布前，家长打开是找不到的。
- 家长能看图，并能单独播放每一段示范。
- 句子和字母都能录、停、听、重录。不勾选同意不能提交，提交第二次会失败。
- 老师能看到提交状态并播放。另一个微信号不能听这段录音，也不能用别人的邀请绑定。
- 直接猜集合或文件地址时，客户端读不到。这一条在云控制台规则生效后才算数。

## 这里还没验证

没有 AppID 和云环境，所以没有部署，也没有在真机或云存储上上传、下载、提交。单元测试用的是内存数据，证明函数会拒绝没有权限的老师、家长、作业和文件。它不能代替控制台里的安全规则。

文件大小和时长按调用时申报的数字检查，上限是这个小程序自己的限制：图片 4MB，音频 8MB，录音 1 秒到 120 秒，格式 jpg/jpeg/png 和 aac/mp3/m4a/wav/silk。没有在云端量真实文件字节。

本地测试：

```bash
npm run test:homework
```
